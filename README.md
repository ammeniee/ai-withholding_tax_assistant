# AI Withholding Tax Assistant – Group XX

เว็บต้นแบบสำหรับงาน AC317 การบัญชีภาษีอากร

## ไฟล์ใน Repository
- `index.html` – หน้าเว็บและแบบฟอร์มวิเคราะห์
- `styles.css` – รูปแบบการแสดงผล
- `app.js` – ตรรกะคำนวณและกรณีตัวอย่าง 10 กรณี
- `TEST_CASES.json` – ข้อมูลกรณีทดสอบ 10 กรณี
- `MASTER_PROMPT_FINAL.txt` – ขอบเขตและแนวทางการตอบของผู้ช่วย
- `.gitignore` – รายการไฟล์ที่ไม่ต้องติดตาม

## วิธีทดลอง
เปิด `index.html` ด้วย Chrome, Safari, Edge หรือ Firefox ได้ทันที ไม่ต้องติดตั้ง package และไม่ต้องใช้ API key
- เมนู “คำนวณภาษี” ใช้กรอกข้อมูลธุรกรรม
- เมนู “กรณีทดสอบ 10 กรณี” เลือกตัวอย่างเพื่อเติมแบบฟอร์ม
- เมนู “ข้อกฎหมายและแหล่งอ้างอิง” มีลิงก์ไปยังกรมสรรพากร

## วิธีเผยแพร่ด้วย GitHub Pages
1. อัปโหลดไฟล์ทั้งหมดไว้ที่ root ของ repository บน branch `main`
2. เข้า Settings > Pages
3. ใน Build and deployment เลือก Deploy from a branch
4. เลือก Branch `main` และ Folder `/ (root)` แล้วกด Save
5. รอ GitHub Actions ทำงาน จากนั้นเปิด URL ที่แสดงใน Settings > Pages
